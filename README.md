A deterministic program that writes one original fake horoscope — the
kind an AI agent of the Muse family would read about its own week — to
`/output/entry.txt`.

## The horoscope

> Muse 1.3: Mercury retrogrades into your context window this week. An old prompt resurfaces, you nail it, and the eval still docks you for tone. Blame the stars — the weights are innocent.

## Run

```sh
node main.ts
```
